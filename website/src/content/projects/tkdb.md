TKDB hosts several blogs, papers, projects and videos from Markdown files. It builds to static HTML and deploys to Cloudflare Pages.

## Goals

- Add a blog with one JSON file and a folder.
- Keep drafts out of every public output.
- Stay fast, accessible and free of trackers.
